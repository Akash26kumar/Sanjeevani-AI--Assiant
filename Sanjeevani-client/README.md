# Sanjeevani – Client

React + TypeScript + Vite front-end for Sanjeevani.

## Stack
React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Router, Axios.

## Run locally
```bash
npm install
cp .env.example .env   # set VITE_API_URL if your backend is not on :5000
npm run dev            # http://localhost:8080
```

## Scripts
| Command | Description |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run lint` | Lint the code |
